# Architecture Decision Records

Short notes on the real forks in the road — what was decided, and why. Add one whenever you make a
choice that would be expensive to reverse or that a future reader (including future-you, or an
interviewer) would ask "why did you do it that way?" about.

Format: context → options considered → decision → consequences. Keep them under a page.
